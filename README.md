# SQL-Data-Cleaning

# Project Overview

This project demonstrates the process of cleaning raw data using SQL and performing Exploratory Data Analysis  to uncover meaningful insights. 

# objectivies
- Clean and preprocess raw data using SQL.
- Handle missing and duplicate records.
- Standardize data formats.
- Correct inconsistent values.
- Perform exploratory data analysis

# Data Cleaning

The data cleaning process includes:

# 1. Removing Duplicate Records
- Identify duplicate rows.
- Keep only unique records.

# 2. Handling Missing Values
- Detect NULL values.
- Replace or remove missing data where appropriate.

# 3. Standardizing Data
- Convert inconsistent text formats.
-  Correcting Inconsistent Values
- Standardize date formats.
- Trim extra spaces.

# 4. Fixing Data Types
- Convert columns to appropriate data types.
- Ensure numerical columns contain valid values.

# 5. Removing Unnecessary Columns
- Drop columns that are not useful for analysis.

# Exploratory Data Analysis (EDA)

The EDA phase focuses on understanding the dataset through SQL queries.

Analysis includes:

- total layoffs
- maximum and minimum layoffs
- maximum and minimum layoffs in single company
- companies with every employee layoff
- total layoffs based on companies,country,industry
- year wise total layoffs and ranking using Window Functions
- rolling layoffs as per month
